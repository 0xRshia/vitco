# آماده‌سازی و بررسی نهایی ویتکو

تاریخ بررسی: ۲۶ اکتبر ۲۰۲۶. محدوده تأییدشده: آماده‌سازی و بررسی محلی؛ پرداخت
حضوری یا هنگام تحویل باقی می‌ماند. این مرحله شامل انتشار، تغییر سرور موجود یا
فعال‌سازی سرویس پیامک و ایمیل نیست.

## تغییرات

- Next.js از 16.3.8 به 16.4.3 ارتقا یافت؛ حداقل نسخه package.json هم افزایش یافت.
  `npm audit` پس از ارتقا صفر آسیب‌پذیری گزارش کرد. این نتیجه تضمین امنیت کل
  برنامه یا تأیید امنیت محیط میزبانی نیست.
- رفتار پیمایش نرم با تنظیم رسمی `data-scroll-behavior="smooth"` با Next.js
  هماهنگ شد. فایل راهنمای عامل نیز توسط نسخه جدید Next.js به‌روز شد.
- فرمان `npm run check:readiness` نسخه Node، نشانی برنامه و کامل‌بودن تنظیمات
  اختیاری سرویس‌ها را بدون نمایش مقادیر محرمانه بررسی می‌کند. گزینه
  `--production` نشانی اصلی HTTPS را الزامی می‌کند. این فرمان پیام نمی‌فرستد
  و اعتبار کلیدها یا تحویل واقعی را تأیید نمی‌کند.
- مقادیر فقط شامل فاصله، ورود پیامکی یا بازیابی ایمیل را فعال نمی‌کنند.

## شواهد بررسی

جریان بررسی: انتخاب محصول توسط مشتری ← محاسبه سرور ← ذخیره سفارش در SQLite ←
تغییر وضعیت توسط صاحب کافه ← نمایش نتیجه به مشتری.

| مورد                               | نتیجه                                                                                                      |
| ---------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| ساخت production و بررسی TypeScript | موفق، با Next.js 16.4.3                                                                                    |
| تست‌های واحد                       | ۱۳ تست موفق، شامل قیمت‌گذاری، دسترسی، ظرفیت و تنظیمات                                                      |
| مسیرهای مرورگر                     | ۲۷ مسیر عمومی/مهمان؛ فارسی و راست‌چین، بدون خطای مرورگر و بیرون‌زدگی افقی در دسکتاپ                        |
| خرید در محیط مجزا                  | ۲ محصول با اندازه بزرگ و افزودنی، هرکدام ۱۳۰ هزار تومان؛ مبلغ ذخیره‌شده ۲۶۰ هزار تومان، دریافت از کافه     |
| تغییر وضعیت                        | اقدام مشتری برای آماده‌سازی با 400 رد شد؛ صاحب کافه وضعیت را تغییر داد و رابط مشتری «آماده تحویل» نشان داد |
| رزرو                               | درخواست ۳ نفر ثبت شد؛ وضعیت pending و ظرفیت باقی‌مانده ۱ از ۴ نفر در سرور تأیید شد                         |
| دسترسی بدون ورود                   | نوشتن سفارش با 401 رد شد                                                                                   |
| مبدأ نامعتبر                       | نوشتن با 403 رد شد                                                                                         |
| سرویس‌های غیرفعال                  | ورود پیامکی و بازیابی ایمیل با 503 و پیام روشن پاسخ دادند                                                  |
| نمایش موبایل                       | خرید/پیگیری و رزرو در عرض ۳۹۳ پیکسل بررسی شدند؛ بدون بیرون‌زدگی افقی                                       |

هفت مسیر اصلی نیز در عرض واقعی ۳۹۳ پیکسل، بدون بیرون‌زدگی افقی بررسی شدند.

قالب‌بندی فایل‌های این مرحله بررسی شد. فرمان سراسری `npm run format:check`
در ۲۱ فایل هشدار دارد: ۲۰ فایل در این مرحله تغییری نکرده‌اند و فایل دیگر
راهنمای تولیدشده خودکار Next.js است. بازقالب‌بندی عمومی مخزن انجام نشده است.

بررسی تعاملی با مرورگر انجام شد؛ مجموعه جداگانه `npm run test:e2e` در این مرحله
اجرا نشد. داده‌های مصنوعی فقط در پایگاه مجزا و موقت استفاده شدند و پس از
بررسی پاک شدند. پایگاه اصلی با این داده‌ها پر نشده است.

## وضعیت اتصال‌ها و گام‌های بعدی

- پرداخت حضوری فعال است؛ درگاه آنلاین یا دریافت اطلاعات کارت اضافه نشده است.
- اتصال کاوه‌نگار و Resend در کد موجود است، ولی کلیدها و فرستنده فعلاً تنظیم
  نشده‌اند. هنگام نیاز، متغیرهای `.env.example` را در محیط خصوصی میزبان تنظیم
  کنید، `check:readiness` را اجرا کنید و سپس تحویل واقعی را با گیرنده مجاز
  بررسی کنید. کلیدها را در چت یا Git قرار ندهید.
- نقشه از OpenStreetMap استفاده می‌کند و به اینترنت نیاز دارد. انتخاب سرویس
  متناسب با ترافیک و شرایط تولید پیش از انتشار بررسی شود.
- کافه واردشده فعلی فقط قابل مرور است؛ برای فروش و رزرو، کافه واقعی باید با
  حساب صاحب کافه ثبت شود و منو، مختصات، ساعات و ظرفیت آن تکمیل شوند.
- SQLite به یک سرور Node با فضای پایدار و پشتیبان‌گیری نیاز دارد. این بررسی
  مهاجرت به دیتابیس اشتراکی یا تأیید تنظیمات سرور خارجی را شامل نمی‌شود.
- تطبیق پیکسلی با فیگما همچنان به دسترسی کامل فایل و دارایی‌های نهایی نیاز دارد.

راهنمای میزبانی موجود در `docs/deployment.md` صرفاً مرجع است؛ سرور توصیف‌شده
در این مرحله بررسی یا به‌روز نشده است.
